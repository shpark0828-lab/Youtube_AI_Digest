📖 Youtube AI Digest 사용자 가이드 (User Guide)

Youtube AI Digest는 등록한 유튜브 채널들의 신규 영상을 매일 아침 자동으로 탐지하고, AI를 통해 단순 요약을 넘어선 초정밀 심층 분석 리포트를 생성해 주는 웹 대시보드 시스템입니다.

본 가이드는 패키지를 전달받은 사용자가 프로그램을 처음 설치하고 구동하여 일상 업무에 완벽히 활용할 수 있도록 작성된 종합 매뉴얼입니다.

#1. 사전 준비 사항 (Prerequisites)

  1. 파이썬 (Python 3.10 이상)
    • 파이썬이 설치되어 있지 않다면 python.org에서 다운로드하여 설치합니다.
    • 설치 시 주의사항: 설치 화면 첫 페이지 하단의 Add Python to PATH 체크박스를 반드시 체크해 주세요.
  2. 웹 브라우저: Chrome, Edge, Firefox 등 최신 모던 브라우저 지원.
  3. (권장) Google Gemini API Key: 무료 발급 가능 (아래 3절 참조).

#2. 초간단 3단계 설치 및 실행 방법

    Step1 --> Step2 --> Step3 --> Step4

[1단계] 압축 해제

전달받은 Youtube_AI_Digest_Package.zip 파일을 원하는 폴더(예: C:\Youtube_AI_Digest 또는 D:\Tools\Youtube_AI_Digest)에 압축 해제합니다.

[2단계] install.bat 실행 (최초 1회)

  • 폴더 내의 install.bat 파일을 더블클릭합니다.
  • 프로그램 구동에 필요한 라이브러리(FastAPI, Uvicorn, youtube-transcript-api 등)가 자동으로 다운로드 및 설치됩니다.
  • 설치가 끝나고 콘솔 창에 패키지 설치가 완료되었습니다. 문구가 뜨면 아무 키나 눌러 창을 닫습니다.

[3단계] run.bat 실행 (프로그램 시작)

  • 폴더 내의 run.bat 파일을 더블클릭합니다.
  • 포트 가용성(기본: 8070)을 자동으로 확인한 후 서버를 구동하며, 준비가 완료되면 기본 웹 브라우저가 자동으로 열립니다.
💡 유용한 팁 (Tip)

포트 자동 전환 기능 탑재

만약 8070 포트를 다른 프로그램이 이미 사용 중이더라도 걱정하지 마세요! run.bat이 스스로 8071, 8072 등 비어 있는 다음 포트를 찾아 자동으로 연결해 줍니다.

#3. API 키 발급 및 등록 가이드

Youtube AI Digest는 무료로 발급받을 수 있는 Google Gemini API를 기본 권장 엔진으로 지원합니다.

Google Gemini API 키 무료 발급 (1분 소요)

  1. Google AI Studio (https://aistudio.google.com/app/apikey)에 구글 계정으로 로그인합니다.
  2. Create API Key 버튼을 클릭하여 새 키를 생성합니다.
  3. 생성된 키 문자열(AIzaSy...)을 복사합니다.

대시보드에 API 키 등록

  1. 웹 대시보드 상단에 보이는 노란색 안내 배너의 입력창에 복사한 키를 붙여넣고 [저장]을 클릭합니다.
  2. 또는 우측 상단의 [⚙️ 스케줄 및 AI 설정] 버튼을 눌러 설정 창에서 키를 입력하고 [API Key 연결 테스트]로 정상 작동 여부를 확인할 수 있습니다.
ℹ️ 참고 (Note)

API 키를 등록하지 않더라도 내장된 스마트 자막 추출 요약기가 기본 작동하지만, 고품질 심층 리포트를 위해 Gemini API 키 등록을 강력히 추천합니다.

#4. 유튜브 채널 등록 및 관리

본 패키지는 초기 상태에 등록된 채널이 없으므로, 원하시는 유튜브 채널을 자유롭게 등록할 수 있습니다.

  1. 채널 등록 창 열기:
    • 상단 채널 바의 [+ 채널 추가] 버튼 또는 우측 상단 [📺 채널 관리] 버튼을 클릭합니다.
  2. 채널 주소 입력:
    • 다음 중 어떤 형식으로 입력해도 자동 인식됩니다:
    • 채널 핸들: @채널명 (예: @PracticalEngineeringChannel)
    • 채널 홈 URL: https://www.youtube.com/@채널명
    • 채널 영상 탭: https://www.youtube.com/@채널명/videos
  3. AI 요약 스타일 선택:
    • 🏗️ 건설 실무 특화: 도면, 시공 공법, 적산, BIM, 현장 안전 중심 분석.
    • 💻 IT / AI / 테크 특화: 코드, 알고리즘, 모델 아키텍처, 개발 프롬프트 중심 분석.
    • 📋 일반 / 비즈니스 범용: 핵심 아이디어, 시사점, 실행 전략 중심 분석.
  4. [채널 등록 및 동기화] 클릭:
    • 등록 즉시 해당 채널의 최신 영상 목록을 자동으로 수집하여 대시보드에 반영합니다.

#5. 핵심 대시보드 기능 활용법

1) 상단 채널 선택 탭

  • [🌐 전체 채널]: 등록된 모든 유튜브 채널의 신규 영상과 요약본을 한 화면에서 통합 모니터링합니다. (기본 화면)
  • [📺 개별 채널 버튼]: 특정 채널 버튼을 누르면 해당 채널의 영상 및 아카이브만 필터링하여 집중 열람합니다.

2) 24시간 신규 영상 스포트라이트 (Spotlight)

  • 상단 배너 영역에 최근 24시간 이내에 새로 업로드된 따끈따끈한 영상이 우선 노출됩니다.
  • 아직 요약되지 않은 영상은 [⚡ AI 심층 요약 생성] 버튼을 눌러 즉시 분석할 수 있습니다.

3) 3단계 맞춤 AI 요약 상세도

요약 모달 창 우측 상단의 상세도 선택기에서 원하는 분석 깊이를 선택하고 즉시 재요약할 수 있습니다:

  • 🔍 초정밀 심층 요약 (Ultra-Detailed): 60초 단위 분초 타임라인 해설, 영상 속 프롬프트/워크플로우 원문 복원, 실무 체크리스트 제공.
  • 🏗️ 적산/견적 특화 분석 (Take-off Focused): 물량 산출식, 규격 변환, 수치 계산 집중 분석.
  • 📋 표준 핵심 요약 (Standard Brief): 핵심 시사점 중심의 빠른 3분 브리핑.

4) 개별 동영상 즉시 추가 ([+ 단일 영상 추가])

  • 채널 전체를 등록하지 않고, 지금 당장 보고 싶은 유튜브 동영상 1개의 URL만 붙여넣어 AI 심층 요약을 생성하고 영구 보관할 수 있습니다.
  • 카테고리 태그(예: AI, Structural Engineering 등)를 지정하여 맞춤 분류가 가능합니다.

5) 리포트 복사 및 마크다운(.md) 다운로드

  • 생성된 AI 요약 리포트는 모달 하단의 [📋 리포트 복사] 또는 [💾 마크다운(.md) 저장] 버튼을 통해 사내 보고서나 노션(Notion), 옵시디언(Obsidian) 문서로 바로 붙여넣을 수 있습니다.

#6. 오프라인 뷰어 (offline_viewer.html) 활용

서버를 실행하지 않고도, 언제 어디서나 인터넷 창만 띄우면 지금까지 작성된 모든 AI 요약 리포트를 검색·열람할 수 있는 100% 독립형 HTML 뷰어가 내장되어 있습니다.

📊 시스템 흐름도 & 아키텍처 다이어그램 
flowchart LR
    ServerRun["웹 대시보드에서\n요약 리포트 축적"] --> Export["웹 화면 [오프라인 뷰어로 내보내기]\n또는 export_offline_viewer.bat"]
    Export --> SingleHTML["단일 파일\noffline_viewer.html 갱신"]
    SingleHTML --> OpenAnywhere["open_offline_viewer.bat\n(파이썬/서버 없이 브라우저 단독 열람)"]
  1. 오프라인 뷰어 열기:
    • 폴더 내의 open_offline_viewer.bat 파일을 더블클릭하거나 offline_viewer.html을 웹 브라우저로 직접 엽니다.
    • 파이썬이나 서버가 꺼져 있어도 즉시 열리며, 검색, 채널별 필터, 모달 열람이 100% 정상 작동합니다.
  2. 최신 요약 데이터 내보내기/갱신:
    • 대시보드 우측 상단의 [오프라인 뷰어] 버튼을 클릭하거나, 폴더 내 export_offline_viewer.bat을 실행하면 현재 DB에 쌓인 모든 요약본이 offline_viewer.html 단일 파일로 즉시 업데이트됩니다.
    • 이 파일 하나만 메일이나 메신저로 다른 팀원에게 전달하면, 팀원은 파이썬 설치 없이도 모든 요약 리포트를 열람할 수 있습니다.

#7. 서버 안전 종료 (stop.bat)

  • 프로그램을 종료하려면 열려 있는 콘솔 창을 닫거나, 폴더 내의 stop.bat 파일을 더블클릭합니다.
  • 백그라운드에서 동작 중이던 포트 8070~8079 범위의 요약기 서버 프로세스가 안전하게 일괄 정리됩니다.

#8. 자주 묻는 질문 (FAQ) & 트러블슈팅

Q1. run.bat을 실행했는데 창이 금방 닫힙니다.

  • 원인: 컴퓨터에 파이썬이 설치되어 있지 않거나, 환경변수(PATH)에 등록되지 않았을 때 발생합니다.
  • 해결: python.org에서 파이썬 설치 파일을 다시 실행하여 Add Python to PATH를 반드시 체크하고 재설치해 주세요.

Q2. 동영상 요약 시 "자막을 가져올 수 없습니다"라는 안내가 나옵니다.

  • 원인: 해당 유튜브 영상 제작자가 자막(자동 생성 자막 포함)을 완전히 비활성화했거나, 연령 제한/비공개 영상인 경우입니다.
  • 해결: 자막이 제공되는 일반 공개 영상에서 요약 기능이 정상 작동합니다.

Q3. 매일 아침 09:00 자동 조사가 작동하려면 컴퓨터를 켜두어야 하나요?

  • 네, 내장 스케줄러(APScheduler)는 프로그램(run.bat)이 실행 중인 상태에서 매일 아침 09:00에 등록된 채널들을 자동으로 방문하여 새 영상을 탐지합니다.
  • 만약 컴퓨터가 꺼져 있었더라도, 나중에 켜서 대시보드 상단의 [⚡ 지금 즉시 24h 조사 실행] 버튼을 누르면 즉시 최근 24시간 영상을 조사하여 요약합니다.
