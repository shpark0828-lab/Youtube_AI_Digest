#2. 세부 구현 단계 (Implementation Phases)

Phase 1. 원본 소스 무결성 보존 및 스테이징 격리

⚡ 중요 (Important)

로컬에서 실행 중인 웹 서버(포트 8070)와 운영 데이터(채널, 영상, 요약, 개인 API 키)는 단 1바이트도 수정하지 않고 읽기 전용으로만 접근하여 100% 안전성을 보장합니다.

  1. 임시 스테이징 디렉토리 분리:
    • 윈도우 임시 디렉토리(%TEMP%\Youtube_AI_Digest_Package)에 전용 빌드 공간을 생성하고 모든 변환 작업을 독립적으로 수행.
  2. 불필요한 대용량/개인 파일 제외 복사:
    • 제외 대상: .venv/(가상환경), __pycache__/ 및 *.pyc(바이트코드 캐시), My_Daily/(개인 엑셀/마크다운 파일), test_crlf.bat, database.db(0바이트 파일).
    • 필수 복사 대상: app.py, run.bat, stop.bat, run.sh, README.md, open_offline_viewer.bat, export_offline_viewer.bat, frontend/, backend/.

Phase 2. [전체 채널] 기본 활성화 및 채널 바 개편

  1. frontend/app.js 기본 채널 선택값 변경:
    • let selectedChannelId = 1; → let selectedChannelId = 'all';로 변경하여, 첫 방문 시 항상 등록된 전체 채널을 취합하는 화면으로 열리도록 설정.
  2. 채널 선택 바(renderChannelSelectorBar) 구조 개선:
    • 채널 선택 바의 가장 첫 번째 항목으로 [전체 채널] 버튼을 고정 배치.
    • 등록된 채널이 0개인 초기 상태에서도 [전체 채널 (0)] 버튼과 함께 직관적인 [+ 채널 추가] 버튼이 즉시 노출되도록 개선.
  3. 헤더 안내 문구(updateHeaderForChannel) 범용화:
    • 채널이 0개일 때: "등록된 유튜브 채널이 없습니다. [채널 관리]에서 채널을 등록해 주세요."
    • 채널이 등록되었을 때: "등록된 전체 유튜브 채널 (N개) 24시간 신규 영상 통합 리포트"
    • frontend/index.html 내 고정 텍스트를 범용 문구로 일괄 정비.

Phase 3. 패키지 배포 편의성 극대화 (원클릭 환경 제공)

  1. 의존성 명세서 (requirements.txt) 생성:
    • 앱 구동에 필요한 6개 핵심 파이썬 패키지를 정확히 명시: ``text fastapi>=0.100.0 uvicorn[standard]>=0.22.0 pydantic>=2.0.0 requests>=2.31.0 apscheduler>=3.10.0 youtube-transcript-api>=0.6.1 ``
  2. 원클릭 인스톨러 (install.bat) 동봉:
    • 파이썬을 잘 모르는 다른 사용자도 더블클릭 한 번으로 pip install -r requirements.txt를 실행할 수 있도록 배치 파일 작성.
  3. 클린 오프라인 뷰어 (offline_viewer.html) 리셋:
    • 0건의 요약 상태를 갖는 초기 템플릿(약 39KB)으로 재구성하여 동봉.
