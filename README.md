# 🏗️ Youtube AI Digest (Daily Video Summarizer)
> **유튜브 채널 등록 및 매일 아침 09:00 자동 조사 및 AI 심층 요약 웹 대시보드**

---

## 🌟 핵심 기능 개요

1. **매일 아침 09:00 자동 스케줄러 (APScheduler 내장)**
   - 매일 오전 9시 정각에 백그라운드에서 유튜브 채널을 자동 방문합니다.
   - 지난 **24시간 이내에 새로 업로드된 동영상**을 자동으로 탐지 및 식별합니다.
   - 신규 영상이 발견되면 자막(Transcript)을 자동 추출하고 AI 심층 분석 요약 리포트를 생성합니다.

2. **24시간 신규 영상 집중 스포트라이트 (Spotlight)**
   - 대시보드 첫 화면에 최근 24시간 이내에 게시된 영상을 강조 표시합니다.
   - 요약본이 없으면 즉시 원클릭으로 요약 생성이 가능하며, 이미 분석된 경우 즉시 리포트를 열람할 수 있습니다.

3. **디테일한 심층 분석 리포트 (Detailed AI Report)**
   단순 3줄 요약이 아닌, 건설 실무자(엔지니어, 시공/공무, 견적사, PM)를 위한 고품질 리포트를 제공합니다:
   - **🎯 핵심 요약 (Executive Summary)**: 영상 전체를 꿰뚫는 명쾌한 2~3문장 서술
   - **💡 주요 핵심 인사이트 (Key Takeaways)**: 영상이 제시하는 5~7가지 핵심 시사점
   - **⏱️ 타임라인별 상세 설명 (Detailed Timeline Breakdown)**: 타임스탬프 구간별 핵심 설명
   - **🛠️ 활용 도구, 프롬프트 & 테크닉 (Tools & Prompts)**: 시연된 AI 모델(GPT, Claude, Astra, Opus 등)과 실제 프롬프트 구조
   - **📋 건설 실무 적용 액션 플랜 (Actionable Recommendations)**: 실무 현장에 바로 적용하는 단계별 가이드
   - **📝 전체 자막 뷰어 & 원클릭 복사/다운로드**: 원본 자막 열람 및 마크다운(.md) 파일 저장 지원

4. **Gemini API 키 등록 및 초정밀 심층 요약 (Ultra-Detailed Mode)**
   - **Google Gemini**의 압도적인 컨텍스트 윈도우를 활용한 3단계 맞춤 상세도 지원:
     - 🔍 **초정밀 심층 요약 (Ultra-Detailed Deep Dive)**: 자막을 60초 단위로 촘촘히 쪼개어 **분초 단위 타임라인 완전 해설**, **영상에 등장한 프롬프트/워크플로우 원문 복원**, **건설 실무 체크리스트**까지 망라
     - 🏗️ **적산/견적 특화 분석 (Take-off & Estimating Focused)**: 2D 도면 -> 3D 변환, 슬래브/벽체/기둥 물량 산출식 및 정확도 집중 해설
     - 📋 **표준 핵심 요약 (Standard Brief)**: 핵심 시사점 중심의 빠른 브리핑
   - **원클릭 빠른 등록**: 대시보드 상단 배너에서 Gemini API Key를 입력하고 버튼 하나로 즉시 저장 가능 (무료 발급: [Google AI Studio](https://aistudio.google.com/app/apikey))
   - **모달 내 즉시 재요약**: 요약 모달에서 원하는 상세도(초정밀 / 적산특화 / 표준)를 선택해 원클릭으로 즉시 다시 요약 가능!
   - **API 키가 없어도 작동**: 키 미등록 시에도 내장 스마트 추출 엔진이 자동으로 작동합니다.

5. **외부 알림 연동 (선택사항)**
   - Discord 또는 Slack Webhook URL을 등록하면 매일 아침 새 영상 요약본이 완성되었을 때 자동으로 메신저 카드 알림을 전송합니다.

## 🚀 빠른 시작 방법 (원클릭 실행)

### 방법 1. 윈도우 원클릭 배치 파일 실행 (가장 간편)
프로젝트 폴더 내의 **`run.bat`** 파일을 더블클릭합니다.
- 필요한 패키지 자동 점검 및 설치
- 웹앱 서버(`http://127.0.0.1:8070`) 자동 기동 (8070 포트가 이미 사용 중인 경우 다음 가용 포트로 자동 전환)
- 기본 웹 브라우저 자동 오픈

### 방법 2. 파이썬 명령어로 직접 실행
```bash
# 1. 패키지 설치
pip install fastapi uvicorn youtube-transcript-api requests apscheduler

# 2. 웹앱 실행
python app.py
```
브라우저에서 `http://127.0.0.1:8070` 으로 접속합니다.

## 🖥️ 화면 구성 안내

1. **대시보드 (Dashboard)**:
   - 상단 통계 카드 (자동 스케줄 상태, 24시간 이내 신규 영상 수, 누적 요약 수, AI 엔진 상태)
   - **[지금 24h 조사 및 요약]** 즉시 실행 원클릭 버튼
   - **최근 24시간 신규 영상 스포트라이트** 카드
   - 최신 상세 요약 리포트 피드

2. **요약 아카이브 (Summaries Archive)**:
   - 지금까지 생성된 모든 요약 리포트 검색 및 필터링
   - 디테일 모달에서 마크다운 전문 복사, `.md` 다운로드, 원본 자막 조회 지원

3. **채널 동영상 전체 목록 (All Videos)**:
   - 등록된 유튜브 채널 채널의 최근 30개 동영상 목록
   - 24시간 이내 여부 태그 및 영상별 개별 AI 요약 요청 버튼

4. **실행 로그 (Run Logs)**:
   - 매일 아침 9시 자동 스케줄 및 수동 실행된 작업 히스토리 (검사 시각, 탐지 영상 수, 요약 성공 여부)

5. **스케줄 & AI 설정 (Settings)**:
   - 자동 실행 시각 변경 (기본값: `09:00`)
   - 조사 대상 시간 범위 (12시간 / 24시간 / 48시간 / 72시간)
   - Gemini / OpenAI API Key 등록 및 실시간 연결 테스트 기능
